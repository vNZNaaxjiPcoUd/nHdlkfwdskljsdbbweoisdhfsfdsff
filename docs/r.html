重點及提要

  • 提供跨平台、跨裝置的雲端筆記服務，無需安裝即可透過瀏覽器直接存取。
  • 採用端對端高強度加密架構，落實本地解密，確保雲端零資料外洩風險。
  • 內建 Markdown 語法、心智圖與多樣化圖表支援，滿足專業排版需求。
  • 具備完整快捷鍵與進階指令系統，大幅提升文件管理與編輯效率。

系統概述與核心功能

雲端筆記本是一款專為機動性與高安全性設計的隨身記事系統。首次開啟時僅需輸入書本名稱與密碼即可建立檔案。系統核心優勢如下：

  • 無縫跨裝置整合：使用者僅需保存專屬網址，即可在個人電腦、平板或手機等設備間流暢作業。於手機瀏覽器中點選「分享/加入主畫面」，即可轉為應用程式 (APP) 形式捷徑。
  • 多元視覺化呈現：系統支援多種瀏覽視角，包含標準閱讀模式、心智圖層級模式，並完美整合 Markdown 語法 與 Mermaid 圖表語法。
  • 彈性分類管理：允許無限制創建多本獨立筆記本，並支援在單一筆記本內新增多個分頁，以便系統化歸檔各類資訊。
